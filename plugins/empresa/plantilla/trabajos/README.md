# Trabajos

Una carpeta por encargo: `AAAA-MM-DD-<tipo>-<asunto-corto>/`.

Cada carpeta contiene:

- `brief.md` — aprobado por una persona antes de redactar (`estado: aprobado`).
- `borrador.md` — pendiente de revisión humana.
- `revision.md` — opcional, si se guarda el informe de revisión.

No borres briefs ni borradores aprobados: son el histórico del proyecto.
