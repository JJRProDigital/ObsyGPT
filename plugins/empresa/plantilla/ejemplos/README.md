# Ejemplos

Guarda aquí piezas reales **ya aprobadas y enviadas**, tres como mínimo por tipo,
con distintas situaciones (buena noticia, mala noticia, petición...).

Cada ejemplo lleva al principio una nota breve:

```
> Situación: (en qué caso se usó)
> Por qué funciona: (qué tiene de bueno: tono, estructura, claridad...)
```

Los tres ejemplos incluidos son ficticios: sustitúyelos en cuanto tengas reales.
